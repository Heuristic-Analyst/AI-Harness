# Learned skills

This folder belongs to the agent. Every skill in here was written by the agent itself, with `create_skill`, and it may improve them with `edit_skill` or remove them with `delete_skill`. Your own skills, one level up in `Skills/`, are out of its reach.

- One folder per skill, with a `SKILL.md` inside: `Skills/Learned/<name>/SKILL.md`. Only such folders are skills. This README, or any other file lying directly in here, is never read as one.
- Every learned skill says `editable: yes` in its header and has a note at the top. The agent's skill list tags them `[editable]`.
- What counts is the folder, not the header: a skill outside this folder that claims `editable: yes` stays locked.
- A learned skill with the same name as one of yours is ignored.

Want to keep one for good? Move its folder up into `Skills/`: from then on it is yours, and the agent can't change it anymore.

Look in here now and then. These are instructions the agent wrote for its future self, and git shows you every change.
